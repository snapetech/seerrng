# YunoHost

:::warning
The package's catalog entry is awaiting review by YunoHost maintainers. Until it
is listed in the official catalog, install it from the dedicated package
repository below.
:::

## Requirements

- YunoHost 12.1.17 or newer.
- An `amd64` or `arm64` server.
- A dedicated domain or subdomain. SeerrNG must be installed at the domain root;
  it does not support installation under a URL path such as `/seerrng`.

The package runs the official SeerrNG Linux release archive as an unprivileged
service, stores the database and settings in YunoHost's persistent app data
directory, and configures YunoHost's Nginx reverse proxy and HTTPS certificate.
YunoHost's LDAP login and single sign-on are not used. Sign-in and user access
are managed by SeerrNG and the media server you connect during setup.

## Install the package

The package is available for manual installation from the
[`seerrng_ynh` repository](https://github.com/snapetech/seerrng_ynh):

```bash
sudo yunohost app install https://github.com/snapetech/seerrng_ynh --debug
```

Choose the dedicated domain and `/` as the installation path. After installation,
open the app URL and complete SeerrNG's first-run setup.

## Upgrade and backups

Use YunoHost's normal app upgrade and backup/restore tools. The package pins
each upstream release archive by SHA-256 and supports YunoHost's app backup and
restore lifecycle. Its source metadata tracks stable SeerrNG releases, and
YunoHost's updater periodically proposes archive URL and checksum changes for
administrators to apply with the normal app upgrade flow. The Node.js 22 runtime
is managed by YunoHost.

Application logs are available from YunoHost's service page and in
`/home/yunohost.app/seerrng/logs/seerr.log` (the data directory uses a different
instance name for additional installations). To inspect service output over
SSH, run `sudo journalctl -u seerrng`.
